# Qloqal — Stitch Dark Marketing Site

Dark-mode B2B SaaS marketing site built from the Stitch reference (`../../stitch dark version /`).

## Tech stack

- **Vite 6** + **React 19** + **TypeScript**
- **TanStack Router** (file-based routing, client-only SPA)
- **Tailwind CSS v4** via `@tailwindcss/vite` (tokens defined in `src/styles.css` `@theme`)
- **Radix UI** primitives (Accordion, Dialog, Slot)
- **lucide-react** icons (replaces Material Symbols from the HTML reference)
- **react-hook-form** + **zod** for forms
- **react-helmet-async** for per-page SEO
- **sonner** for toasts
- **framer-motion** available for richer animations as needed

## Local development

```bash
pnpm install
pnpm dev          # http://localhost:5173
pnpm build        # production bundle in ./dist
pnpm preview      # serve the built bundle on :4173
pnpm typecheck    # tsc -b
```

> First `pnpm dev` / `pnpm build` regenerates `src/routeTree.gen.ts` from the
> `src/routes/*.tsx` files. The file is git-ignored.

## Deploying to Vercel

The `vercel.json` ships with everything needed:

- `framework: vite` so Vercel uses the right defaults
- SPA rewrite (`/(.*)` → `/`) so client-side routes resolve on hard reload
- Cache-Control on `/assets/*` for hashed bundles
- Security headers (CSP-lite, no clickjacking, no MIME sniffing)

### One-shot deploy

```bash
# from website/stitch-dark/app
pnpm install
pnpm build       # smoke test locally first
npx vercel       # follow prompts
npx vercel --prod
```

### Connecting the repo to Vercel UI

1. Push to GitHub.
2. In Vercel → New Project → import the repo.
3. Set **Root Directory** to `website/stitch-dark/app` (Vercel will pick up `vercel.json`).
4. Build & Output settings auto-detect from `vercel.json`. Environment variables are
   not required for the current scope — forms are stubbed (`console.log` + sonner toast).

## Design tokens

All colors, type scale, spacing, and radii live in `src/styles.css` under the
`@theme` block — no `tailwind.config.js`. Edit there to retune the palette.

Custom utilities:
- `glass-card` — translucent surface + 20px backdrop blur + 1px white/10 border
- `glow-hover` — adds primary green glow on hover (transition built-in)
- `gradient-border` — bento tile pattern (1px transparent border with diagonal gradient)
- `hero-gradient` — twin radial glows top-right (green) + bottom-left (blue)
- `text-gradient-primary` — green gradient for accent text spans
